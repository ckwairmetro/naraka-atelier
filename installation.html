Set up on your PC

  1. Extract the ZIP

    Choose Extract All in File Explorer. Keep _internal beside NarakaAtelier.exe.

  2. Open Atelier

    Close Naraka and its launcher. Open NarakaAtelier.exe. If asked, select the folder containing NarakaBladepoint.exe.

  3. Apply your settings

    Wait for Atelier to verify the client. Choose and apply your cosmetics while Naraka is closed. Launch the game after Atelier finishes.

Need help starting Atelier?

If the app window fails to open, install Microsoft Evergreen WebView2. For client mismatches or a custom install path, see the compatibility guide.

安装 Naraka Atelier

自定义《永劫无间》在本机显示的外观。Windows 发布包已内置外观目录和 Python 运行环境。

Windows 版下载

Atelier v0.2.9.2 · Windows 10/11 64 位
Steam 构建 26771036 · 客户端 1.5.9.2

下载 Atelier ZIP

请登录有权访问此私有仓库的 GitHub 账号。

电脑安装步骤

  1. 解压 ZIP

    在文件资源管理器中选择全部解压缩。请将 _internal 文件夹与 NarakaAtelier.exe 保留在同一目录。

  2. 打开 Atelier

    退出游戏及其启动器，运行 NarakaAtelier.exe。如提示选择目录，请选取包含 NarakaBladepoint.exe 的文件夹。

  3. 应用外观设置

    等待 Atelier 验证客户端。在游戏关闭时选择并应用外观，等 Atelier 完成后再启动游戏。

Atelier 无法启动？

如果应用窗口无法打开，请安装微软 Evergreen WebView2 运行时。如遇客户端不匹配或需要手动指定目录，请参阅兼容性说明。
